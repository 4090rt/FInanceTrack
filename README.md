# 💰 FinanceTrack

**Персональный трекер расходов для развития финансовой дисциплины**

FinanceTrack — это минималистичное приложение для ручного учета личных финансов, которое помогает контролировать расходы и развивать финансовую дисциплину через осознанное внесение операций.

## 🎯 Основная идея

Принцип прост: **чем больше усилий вы прикладываете для учета, тем осознаннее становитесь в расходах**. 

В отличие от автоматических банковских агрегаторов, FinanceTrack требует **ручного внесения** каждой операции. Это сознательное решение — процесс ручного ввода заставляет задуматься над каждой тратой, формируя привычку ответственно относиться к финансам.

## ✨ Особенности

- **📊 Учет операций**: Добавление расходов с указанием категории, даты и суммы
- **🗂️ Система категорий**: Гибкая система категорий для классификации расходов
- **📈 Статистика**: Наглядная визуализация финансовой статистики
- **🔒 Конфиденциальность**: Все данные хранятся локально на устройстве
- **🌐 Минимальные требования к сети**: Работает полностью оффлайн, кроме получения курсов валют
- **🎯 Простой интерфейс**: Минималистичный и интуитивно понятный дизайн
- **💪 Развитие дисциплины**: Формирование привычки регулярно отслеживать финансы
